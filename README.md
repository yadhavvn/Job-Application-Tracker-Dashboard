# Job Application Tracker Dashboard

## Project Overview
An interactive Excel dashboard designed to track and analyse job applications, monitor application statuses, and understand job search progress.

## Features
- Interactive dashboard with Excel slicers
- KPI cards for application tracking
- Charts and visual reports
- Pivot tables for data summarisation
- Full-screen dashboard presentation using VBA macros
- One-click full-screen toggle
- Automated zoom-to-fit screen display

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- VBA Macros
- Data Visualisation

## Workbook Structure
- **Dashboard:** Interactive visual dashboard
- **Pivot:** Pivot tables and supporting calculations
- **Data:** Source dataset

## How to Use
1. Download the `.xlsm` workbook.
2. Open it using Microsoft Excel Desktop.
3. Enable macros if prompted and if you trust the workbook.
4. Navigate to the Dashboard sheet.
5. Use slicers to filter and explore the data.
6. Use the full-screen icon for presentation mode.

## Project Objective
To build a practical job application tracking system that transforms application data into meaningful insights through interactive visualisation.
